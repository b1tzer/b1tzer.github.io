# 整体架构

## 1. 三层架构

```
┌─────────────────┐
│   连接层         │  认证、线程池、连接管理
├─────────────────┤
│   服务层         │  SQL 解析、优化、执行
│   ├─ 解析器      │  语法分析、语义分析
│   ├─ 优化器      │  执行计划选择
│   └─ 执行器      │  调用存储引擎接口
├─────────────────┤
│   存储引擎层     │  InnoDB/MyISAM/Memory
└─────────────────┘
```

## 2. SQL 执行流程

```
Client → 连接器 → 查询缓存(8.0移除) → 解析器 → 优化器 → 执行器 → 存储引擎
```

## 3. InnoDB 架构

```
┌─────────────────────────────────────┐
│           InnoDB 存储引擎            │
├─────────────────────────────────────┤
│  内存结构                            │
│  ├─ Buffer Pool                     │
│  ├─ Change Buffer                   │
│  ├─ Adaptive Hash Index             │
│  └─ Log Buffer                      │
├─────────────────────────────────────┤
│  磁盘结构                            │
│  ├─ 系统表空间                       │
│  ├─ 独立表空间 (.ibd)                │
│  ├─ Redo Log                        │
│  └─ Undo Log                        │
└─────────────────────────────────────┘
```
