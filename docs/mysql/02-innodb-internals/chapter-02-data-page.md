# 数据页与行格式

## 1. 数据页结构 (16KB)

```
┌─────────────────┐
│ File Header     │  38字节
├─────────────────┤
│ Page Header     │  56字节
├─────────────────┤
│ Infimum/Supremum│  26字节
├─────────────────┤
│ User Records    │  用户记录
├─────────────────┤
│ Free Space      │  空闲空间
├─────────────────┤
│ Page Directory  │  页目录
├─────────────────┤
│ File Trailer    │  8字节
└─────────────────┘
```

## 2. 行格式

### Compact 格式
```
┌─────────────────┐
│ 变长字段长度列表 │
├─────────────────┤
│ NULL 标志位      │
├─────────────────┤
│ 记录头信息       │  5字节
├─────────────────┤
│ 隐藏列          │  DB_ROW_ID/DB_TRX_ID/DB_ROLL_PTR
├─────────────────┤
│ 用户数据         │
└─────────────────┘
```

### Dynamic 格式 (默认)
- 与 Compact 类似
- 大字段完全溢出，只存 20 字节指针

## 3. 页分裂

当页满时插入新记录，会发生页分裂：
1. 申请新页
2. 将一半记录移到新页
3. 更新指针
