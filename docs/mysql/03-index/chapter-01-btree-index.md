# B+ 树索引

## 1. 聚簇索引

- 主键索引，叶子节点存储完整行数据
- 一个表只能有一个聚簇索引
- InnoDB 默认使用主键作为聚簇索引

## 2. 二级索引

- 非主键索引，叶子节点存储主键值
- 查询需要回表（通过主键到聚簇索引查完整数据）

## 3. B+ 树结构

```
        [10 | 20 | 30]           ← 非叶子节点（只存键值）
       /    |    |    \
   [1-9] [11-19] [21-29] [31-40] ← 叶子节点（存数据或主键）
     ←─────────────────────→     ← 双向链表
```

## 4. 回表

```sql
-- 二级索引查询
SELECT * FROM users WHERE name = '张三';
-- 1. 在 idx_name 二级索引找到 name='张三' 的主键 id=5
-- 2. 回表：用 id=5 到聚簇索引查完整行数据
```

## 5. 索引下推 (ICP)

```sql
-- MySQL 5.6+ 支持
SELECT * FROM users WHERE name LIKE '张%' AND age = 25;
-- 在索引层直接过滤 age，减少回表次数
```
