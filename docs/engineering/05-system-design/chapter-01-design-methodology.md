# 系统设计方法论

## 1. 设计流程

```
需求分析 → 概要设计 → 详细设计 → 评审 → 实现
```

## 2. 需求分析

- 功能需求：系统做什么
- 非功能需求：性能、可用性、扩展性

## 3. 概要设计

- 系统架构图
- 模块划分
- 接口定义
- 数据流图

## 4. 详细设计

- 类图
- 时序图
- 状态图
- ER图

## 5. 设计文档模板

```markdown
# 系统设计文档

## 1. 概述
## 2. 需求分析
## 3. 架构设计
## 4. 模块设计
## 5. 接口设计
## 6. 数据设计
## 7. 非功能需求
## 8. 风险与对策
```
