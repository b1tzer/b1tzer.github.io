# 敏捷开发

## 1. Scrum

| 角色 | 职责 |
|------|------|
| Product Owner | 需求管理、优先级排序 |
| Scrum Master | 流程守护、障碍移除 |
| Development Team | 跨职能团队 |

| 仪式 | 频率 | 时长 |
|------|------|------|
| Sprint Planning | 每 Sprint 开始 | 2-4h |
| Daily Standup | 每天 | 15min |
| Sprint Review | 每 Sprint 结束 | 1-2h |
| Retrospective | 每 Sprint 结束 | 1h |

## 2. Kanban

- 可视化工作流
- 限制在制品（WIP）
- 管理流动
- 持续改进

## 3. 敏捷 vs 瀑布

| 特性 | 敏捷 | 瀑布 |
|------|------|------|
| 需求 | 可变 | 固定 |
| 交付 | 持续 | 一次性 |
| 反馈 | 快速 | 延迟 |
| 风险 | 早期发现 | 后期发现 |
