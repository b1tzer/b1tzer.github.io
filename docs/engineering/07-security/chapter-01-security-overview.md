# 安全概览

## 1. OWASP Top 10

| 排名 | 风险 | 说明 |
|------|------|------|
| A01 | 访问控制失效 | 未授权访问 |
| A02 | 加密失败 | 敏感数据泄露 |
| A03 | 注入 | SQL/NoSQL/命令注入 |
| A04 | 不安全设计 | 设计缺陷 |
| A05 | 安全配置错误 | 默认配置、错误信息泄露 |
| A06 | 脆弱过时组件 | 使用有漏洞的依赖 |
| A07 | 认证失败 | 弱密码、会话管理 |
| A08 | 软件和数据完整性失败 | 未验证更新、CI/CD漏洞 |
| A09 | 安全日志和监控失败 | 缺少审计日志 |
| A10 | SSRF | 服务端请求伪造 |

## 2. 安全原则

- 最小权限原则
- 纵深防御
- 安全默认
- 失败安全

## 3. 安全开发生命周期

```
需求 → 设计 → 编码 → 测试 → 部署 → 运维
 ↑       ↑      ↑      ↑      ↑      ↑
威胁建模 安全设计 安全编码 安全测试 安全配置 监控响应
```
