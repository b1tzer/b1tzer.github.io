# 软件工程概览

## 1. 什么是软件工程

将系统化、规范化、可量化的方法应用于软件开发、运行和维护。

## 2. 核心目标

| 目标 | 说明 |
|------|------|
| 正确性 | 满足需求规格 |
| 可靠性 | 在规定条件下完成功能 |
| 可维护性 | 易于修改和扩展 |
| 可复用性 | 组件可在不同项目复用 |
| 效率 | 合理使用资源 |

## 3. 软件开发生命周期

```
需求分析 → 设计 → 编码 → 测试 → 部署 → 维护
```

## 4. 开发模型

| 模型 | 特点 | 适用场景 |
|------|------|---------|
| 瀑布 | 线性顺序 | 需求明确 |
| 迭代 | 分批次交付 | 需求渐进 |
| 敏捷 | 快速迭代 | 需求多变 |
| DevOps | 开发运维一体化 | 持续交付 |

## 5. 核心价值观

- **人** over 流程
- **可工作软件** over 详尽文档
- **客户协作** over 合同谈判
- **响应变化** over 遵循计划
