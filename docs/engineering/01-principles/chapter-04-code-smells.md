# 代码坏味道

## 1. 代码坏味道列表

| 坏味道 | 说明 | 重构方法 |
|--------|------|---------|
| 重复代码 | 多处相同逻辑 | 提取方法/超类 |
| 过长方法 | 方法超过 20 行 | 提取方法 |
| 过大类 | 类承担过多职责 | 提取类 |
| 过长参数列表 | 参数超过 3-4 个 | 引入参数对象 |
| 发散式变化 | 一个类因多种原因修改 | 提取类 |
| 霰弹式修改 | 一个修改涉及多个类 | 移动方法/内联 |
| 依恋情结 | 方法过多使用其他类数据 | 移动方法 |
| 数据泥团 | 多个数据项总是一起出现 | 提取类 |
| 基本类型偏执 | 滥用基本类型 | 引入值对象 |
| switch 过多 | 大量 if-else/switch | 多态 |
| 平行继承体系 | 子类数量同步增长 | 合并 |
| 冗余类 | 类没有存在的价值 | 内联类 |
| 过度耦合 | 类之间依赖过深 | 提取接口 |
| 纯数据类 | 只有 getter/setter | 封装行为 |

## 2. 如何识别

- Code Review
- 静态分析工具（SonarQube）
- 代码复杂度指标
