## 2. 核心组件

| 组件 | 说明 |
|------|------|
| Broker | 存储消息，处理请求 |
| ZooKeeper/KRaft | 集群协调，元数据管理 |
| Producer | 发送消息到 Topic |
| Consumer | 从 Topic 消费消息 |
| Connect | 连接外部系统 |
| Streams | 流处理 API |
